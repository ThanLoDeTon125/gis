# Project notes

## Design preferences (persistent)
- Never use the "rounded card with a colored left-border accent" pattern. It reads as AI slop.
  Prefer restrained, typographic lists: hairline separators, small status dots, hover states —
  boxes only when they carry real grouping meaning.
- Tooltips: custom CSS tooltips (anchor positioning), never the native `title` attribute.
- Vietnamese copy must be idiomatic, not calques of English terms (e.g. "evidence bar" →
  "mức bằng chứng", not "thanh bằng chứng"). Nav labels must be self-explanatory.
- Numbers shown in one view must come from one source of truth — never two counts of the same thing.
